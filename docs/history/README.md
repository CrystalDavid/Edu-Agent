# Edu-Agent 历史资料索引

> 状态：HISTORICAL
>
> 默认行为：工程 Agent、产品 Agent 和 UI Agent **不得主动读取本目录**。

这里保存当时准确、但已经不再代表当前产品或架构的记录。只有在用户明确要求追溯历史、核对某个 Gate/决策，或当前权威文档明确引用某项证据时，才读取对应的单个文件；不要为了“理解项目”批量扫描本目录。

当前事实请返回 [文档入口](../README.md)。历史内容与当前代码冲突时，以当前权威文档、代码和自动化验证为准。

| 目录 | 内容 | 允许的使用场景 |
|---|---|---|
| `architecture/` | 已实施阶段报告、旧模块设计和早期 ADR | 追溯架构决策演进或实施证据 |
| `gates/` | 已完成 Gate 的设计与验收证据 | 核对某个 Verified Gate |
| `project/` | 已完成的仓库清理、同步和结构决策记录 | 追溯仓库治理历史 |
| `research/` | 早期研究、红队审查和方案探索 | 用户明确要求研究背景时 |
| `ui/` | 旧 UI 方案、阶段报告和历史截图 | 对比历史视觉方向时 |

历史目录只接受有追溯价值的最终记录，不接收草稿、临时审计、待评审计划或新的当前规范。
