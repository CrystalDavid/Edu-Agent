# Teaching Workspace 教学信息架构

> 状态：DESIGN ONLY
>
> 本文只定义教师视角的信息层级、切换规则和历史组织方式；不修改数据库、API、Migration、CourseRun、Lesson 或 TeachingPlan 的正式语义。

## 1. 设计结论

Teaching Workspace 不应把 `CourseRun → CurriculumUnit → Lesson → Revision` 的数据库结构直接展示给教师。教师进入教学页时，真正需要回答的是：

1. 我现在教哪些课？
2. 当前班级进行到哪里？
3. 这节课系统已经准备了什么？
4. 现在只需要我做哪个判断？
5. 以前教过的内容在哪里复用？

推荐的教师视角层级是：

```text
教学时间范围
└── 教学任务组（学科 + 年级）
    └── 班级
        └── 单元
            └── 课时
```

其中“当前学期”不是课程名称的一部分，而是整个教学工作区的时间范围；“班级”不是最高层，因为同一教师常常给多个班教授同一学科和年级，这些班级共享课程结构，但拥有各自的进度、作业、Evidence、课堂记录和反思。

## 2. 为什么班级不放在最高层

班级放在最高层会产生三个问题：

- 同一套八年级数学单元会在 2 班、3 班、4 班下重复出现；
- 教案、教学方案和材料的复用关系被班级目录切断；
- 教师切换班级时难以比较“同一课时在不同班级的实际进度和调整”。

因此推荐：

- **课程结构**按“学科 + 年级 + 学期课程版本”组织；
- **教学执行**按班级对应的 CourseRun 组织；
- **共享内容**允许从其他班级或历史学期复用，但采用后必须形成当前 CourseRun 下可追溯的版本；
- **班级事实**始终保持隔离，作业、Submission、Evidence、Delivery、Observation 和 Reflection 不跨班混用。

对于班主任按班级查看学生事务的需求，应由“学生”或未来班级工作台承担，而不是改变教学页的课程层级。

## 3. 当前教学

### 3.1 默认入口

教师打开“教学”时默认进入“当前教学”，系统从会话中的当前学校、教师 CourseRun 授权和当前有效学期计算可见范围，不要求教师手动输入 tenant、学校或教师身份。

页面顶部只显示一次当前范围：

```text
当前教学                         2026 春季学期
数学 · 八年级                   3 班  4 班
```

不再重复显示：

```text
数学 / 八年级 / 当前学期 / 八年级 3 班 / 第 1 单元 / 一次函数
```

### 3.2 多学科与多年级

当教师只有一个“学科 + 年级”教学任务组时，不显示多余选择器，直接进入该组。

当教师教授多个学科或年级时，顶部使用紧凑的教学任务组切换器：

```text
[数学 · 八年级]  [数学 · 九年级]  [科学 · 七年级]
```

每个教学任务组内部再显示班级切换：

```text
[3 班] [4 班] [5 班]
```

切换班级后：

- 单元和课时结构可以保持相同；
- 当前进度、准备状态、作业、Evidence、Delivery 和 Reflection 必须重新读取；
- 页面不得残留上一个班级的缓存内容；
- URL 应包含稳定的 CourseRun / Lesson 上下文，以便刷新、分享受控链接和浏览器返回。

### 3.3 当前教学排序

当前教学按以下优先级排序：

1. 今天和未来七天有课的教学任务组；
2. 存在待教师判断、待确认材料或待课后反馈的教学任务组；
3. 其他当前有效 CourseRun；
4. 已结束但仍处于当前学期收尾期的 CourseRun。

班级默认恢复教师最近使用的选择；若没有历史选择，则选择今天最近一节课所属班级，而不是固定选择第一个数据库记录。

## 4. 单元与课时

### 4.1 单元是教师进入课时前的教学语境

点击单元后，主区域先显示单元概览：

- 单元核心目标；
- 关键概念和前后关系；
- 单元教学重点与共性难点；
- 当前班级的单元进度；
- 尚需处理的课时；
- 已产生的方案和材料数量；
- 与该单元相关的班级 Evidence 摘要。

这些内容来自现有 CurriculumUnit、LearningObjective、Lesson、Task、TeachingPlan、MaterialBundle 和 Evidence 的授权读取，不新增“单元工作台”事实表。

### 4.2 课程树交互

左侧课程树使用两层结构：

```text
第 1 单元  一次函数                 3 / 5 课时
  第 1 课时  变量与函数             已完成
  第 2 课时  一次函数的概念         已完成
  第 3 课时  斜率与图像变化         待确认材料
  第 4 课时  待定系数法             待备课
  第 5 课时  一次函数的应用         未开始
```

交互规则：

- 单元可以展开和收起；
- 一次只默认展开当前课时所在单元，教师可以手动展开多个单元；
- 展开状态属于页面导航偏好，不是业务状态；
- 同一浏览会话内保持展开状态，刷新时可从 URL 中的 unit / lesson 恢复当前单元；
- 动画只改变高度和透明度，持续 160–220ms，不让内容跳动；
- 展开控件有明确的 `aria-expanded`，但不在目标、重点、正文等内容上使用隐藏式小箭头；
- 点击单元标题选择单元，点击独立展开控件展开或收起，避免一个点击同时承担两个含义；
- 点击课时进入 Lesson Workspace，浏览器返回恢复原班级、单元、滚动位置和展开状态。

### 4.3 信息去重

每一级只负责一次上下文表达：

| 层级 | 显示内容 | 不再重复 |
|---|---|---|
| 页面范围 | 当前 / 历史、学期 | 课时卡不再写“当前学期” |
| 教学任务组 | 学科、年级 | 单元标题不再重复学科和年级 |
| 班级切换 | 班级 | 每个课时标题不再重复“八年级 3 班” |
| 单元 | 单元序号、名称、进度 | 课时头部不再重复完整课程路径 |
| 课时 | 课时序号、名称、上课时间 | Journey 卡不再重复课时名称 |

课时页的紧凑上下文建议只显示：

```text
一次函数 · 第 3 课时
斜率与图像变化                     9 月 18 日 08:30
```

班级和学期已在页面范围中明确时，不再次写入标题；当课时以深链接单独打开时，才在次级位置补充“八年级 3 班 · 2026 春季”。

## 5. 历史教学

### 5.1 独立入口，不与当前课程混排

“历史教学”位于当前教学之后，默认收起为一个明确入口：

```text
历史教学
查看以前学期的课程、教案和材料
```

进入后先按学期倒序组织：

```text
2025 秋季学期
  数学 · 八年级
    2 班   已结束
    3 班   已结束

2025 春季学期
  数学 · 七年级
    1 班   已结束
```

历史区域支持按学期、学科、年级、班级筛选，但不把全部筛选器常驻在当前教学页面。

### 5.2 历史内容的操作边界

历史课程默认只读，可执行：

- 查看已批准 TeachingPlan；
- 预览和下载历史材料；
- 查看课堂记录、反思和 Evidence 来源；
- 将某份方案或材料作为当前课时的复用起点。

“复用”不能把历史文件或 TeachingPlan 直接改成当前事实。系统应创建当前 CourseRun 下的新 Task、Proposal 或 FileVersion，并保留来源关系。

历史班级的学生数据仍遵守学校、CourseRun 和 learner 权限。即使教案可复用，也不能把历史匿名学习者 Evidence 自动带入当前班级。

## 6. 学期切换逻辑

学期选择器表达时间范围，而不是普通标签：

- 默认值由学校当前学期配置或有效 CourseRun 推导；
- 当前学期放在首位并标记“当前”；
- 历史学期倒序排列；
- 没有 CourseRun 的学期不显示空壳；
- 切换学期后重新计算教学任务组和班级，不保留不属于该学期的选择；
- 从历史详情返回时恢复原历史学期和筛选条件；
- 学期切换不修改任何正式业务状态。

URL 建议保存 `term`、`courseRun`、`unit`、`lesson` 的导航上下文，但前端提交的这些值仍需服务端 ActingContext 和权限校验。

## 7. 数据映射

| 教师界面概念 | 正式数据来源 | 说明 |
|---|---|---|
| 当前 / 历史学期 | School / CourseRun 的有效时间和学期字段 | 读取解释，不复制状态 |
| 教学任务组 | 授权 CourseRun 按 subject + grade + curriculum version 聚合 | 读取投影 |
| 班级切换 | CourseRun | 每个班级保持独立运行状态 |
| 单元树 | CurriculumUnit | 同课程结构可跨班展示 |
| 课时与进度 | Lesson + LessonJourneyProjection | Journey 只是读取解释 |
| 单元目标 | LearningObjective + Unit / Lesson 关联 | 不由前端拼成新事实 |
| 历史教案与材料 | TeachingPlan Revision + FileAsset / FileVersion | 历史版本不可覆盖 |
| 班级差异 | Assignment Evidence、Delivery、Observation、Reflection | 严格限定 CourseRun |

## 8. 空状态与异常状态

- 当前没有教学任务：显示“当前学期还没有分配课程”，提供联系管理员或切换历史教学，不生成虚假课程；
- 一个教学任务组只有一个班级：隐藏班级切换控件，但显示一次班级名称；
- 学期配置缺失：根据 CourseRun 时间显示“未标注学期”，不猜测春季 / 秋季；
- 历史 CourseRun 缺少完整单元：仍允许查看已有 Lesson、Plan 和 File，不伪造缺失结构；
- 权限变化：清除当前选择并返回授权范围，不在错误信息中泄漏原资源；
- 跨班同课进度不同：每次切换重新读取，绝不沿用上个班级的 Journey 状态。

## 9. 验收标准

设计实施后应满足：

- 当前教学始终先于历史教学；
- 教师只看到一次学科、年级、学期和班级上下文；
- 多班教师能在同一学科 / 年级下快速切班；
- 多学科、多年级教师能切换教学任务组；
- 单元可以展开、收起，并恢复导航状态；
- 历史教案和材料可查看、可受控复用，历史事实不可覆盖；
- 切班、切学期和修改 URL 都经过正式权限校验；
- CourseRun、Lesson、TeachingPlan、Evidence 和 File 仍是唯一正式真值。
