# 教师日程页重设计交付报告

## 交付范围

本轮将日程页从“列表式展示”升级为真实 PostgreSQL 数据驱动的教师日程工作台，未改变 Todo、CalendarEvent、来源业务投影的状态所有权。

### 页面与组件

- `TeacherSchedulePage`：统一加载当前日历范围、统计范围、个人待办和来源业务投影。
- `ScheduleComponents`：重写日、周、月视图，增加统一事件分类、新建/编辑日程弹窗、极简待办清单和时间分布统计。
- `TeacherSidebar`：扩大点击热区、统一字号和图标比例，移除教师信息右侧无意义的省略号。
- `teacher-portal.css` / `design-tokens.ts`：形成 4/8/12/16/24/32 间距节奏、14/24/999 圆角层级和更舒展的教师门户字号。

## 日程能力

- 日视图使用 06:00—22:00 时间网格，事件块高度由真实时长计算。
- 周视图使用七列共享时间轴，并单独展示全天事项。
- 月视图使用固定六周网格，每日最多展示三条事项，超出部分显示“还有 N 项”。
- 点击月视图日期可进入对应日视图。
- 上课、会议、备课、巡班/值班、批改、个人提醒、学校事务和其他具有固定且一致的柔和配色。
- 手工日程可新建和编辑；来源业务事项保持只读并跳回源页面。

## 新建日程

- 标题统一为“新建日程”。
- 字段保留标题、类型、全天、开始、结束和可选说明。
- 日期与时间拆分，避免浏览器原生 `datetime-local` 弹层在不同平台出现难用的多列滚动器。
- 全天日程关闭时间输入；结束时间必须晚于开始时间。

## 待办与统计

- 主界面只保留“进行中”和“已完成”。
- 个人待办与来源业务提醒进入同一列表。
- 个人待办可点击圆形检查按钮完成；来源提醒只能进入源业务处理，不提供伪造完成按钮。
- 统计支持今日、本周和本月切换，按照实际日程时长计算分类占比。
- 稍后提醒、取消等能力仍保留在后端契约中，但不再占用本轮主界面。

## 林老师示例数据

示例数据仅由显式 `pnpm sample:seed` 写入 PostgreSQL。产品运行时仍通过正式 Session、ActingContext、API 和 Repository 读取，不直接依赖静态样例包。

当前月份会生成：

- 81 条真实 CalendarEvent，覆盖 7 个教师日程分类；
- 4 条进行中个人待办；
- 3 条已完成个人待办；
- 工作日课程、集体备课、批改、会议、值班、学校事务和个人资料整理；
- 一条全天学校活动。

Seed 使用正式 Work Repository、AuthorizationDecision、Idempotency、Outbox 和 Audit 路径；同月重复执行不会创建重复数据。

## 数据与迁移

新增前向 Migration `0010_calendar_event_categories.sql`，只扩展 `CalendarEvent.event_type` 检查约束，使 `duty` 和 `school_affair` 能成为可持久化、可统计的一等分类。43 个历史 Migration 和 Phase 7A Migration 均未修改。

## 边界

- 未增加复杂重复规则、共享日历、外部日历同步或项目管理字段。
- 未让工作台投影成为第二业务真值。
- 未改变 Todo 完成、来源业务处理、Agent handoff 或现有权限语义。
- 地点字段暂未加入数据模型；当前教师工作流没有稳定的地点真值，避免为单一表单字段增加无来源的长期状态。
