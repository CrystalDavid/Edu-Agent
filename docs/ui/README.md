# Edu-Agent 冻结 UI 规范

> 状态：**FROZEN / 当前唯一视觉依据**
> 生效日期：2026-08-15
> 适用范围：`apps/web` 的登录页、教师端侧边栏、日程、课程、学情、资料页与公共控件
> 原则：后续没有重大可用性、可访问性、响应式或安全问题，不得随意改动本文件冻结的设计。

本规范用尺寸、颜色、状态和代码描述设计，不以参考图片作为实现依据。图片只能用于验收对比，不能替代下面的数值与代码。

## 1. 变更纪律

以下内容属于冻结项：

- 登录页整体尺寸、左右比例、背景、SVG 插画、字体层级和表单布局。
- 教师端侧边栏宽度、底色、头像、导航尺寸、图标尺寸和选中状态。
- 所有“多选一”胶囊选择器的轨道、选中块、文字颜色和阴影。
- “新建日程”“新建待办”这类页面级创建按钮的尺寸与样式。
- 所有文字按钮的胶囊圆角、图标按钮的正圆外形和主按钮 Hover 状态。
- 全局字体族与字号令牌。
- 日历内容容器的圆角、边框和裁切方式。

只有以下情况可以修改冻结项：

1. 真实功能无法使用，例如控件被遮挡、点击区域错误或登录失败。
2. 无障碍问题，例如键盘无法操作、缺少焦点态或对比度不达标。
3. 主流目标分辨率下发生严重溢出或布局断裂。
4. 用户明确要求修改冻结设计。

任何修改都必须同时更新本文件，并完成桌面端截图、窄屏检查、控制台检查、类型检查和生产构建。

## 2. 全局字体

### 2.1 字体分工

| 文本 | 字体 | 说明 |
|---|---|---|
| 英文、数字、拉丁标点 | `Nunito` | 使用本地可变字体，范围 `200–900` |
| 简体中文 | `Noto Sans SC Variable` | 使用 `@fontsource-variable/noto-sans-sc`，范围 `100–900` |
| 等宽诊断信息 | `Nunito` → `Noto Sans SC Variable` → `Consolas` | 中文仍必须先落到 Noto Sans SC |

统一字体栈：

```css
:root {
  --font-ui:
    "Nunito",
    "Noto Sans SC Variable",
    "Noto Sans SC",
    sans-serif;
}
```

Nunito 的字体文件只覆盖拉丁字符，因此中文会自然落到第二项 Noto Sans SC；不要为中英文分别包裹额外标签。

此前中文使用的 `PingFang SC / HarmonyOS Sans SC / Microsoft YaHei` 已退出主字体栈，只能作为历史资源存在，不得重新设为界面主字体。

### 2.2 字号保持不变

字体替换不得顺便改变字号。当前令牌固定如下：

| 层级 | 字号 | 字重 | 用途 |
|---|---:|---:|---|
| Display | `32px` | 700 | 特殊大标题 |
| Page title | `28px` | 700 | 页面唯一主标题 |
| Section title | `20px` | 600 | 普通分区标题 |
| Schedule / Todo title | `28px` | 700 | 日程页左右主区域标题，二者必须同高同基线 |
| Content title | `16px` | 500 | 卡片、列表内容标题 |
| Body | `15px` | 400 | 正文与表单正文 |
| Caption | `13px` | 400 | 时间、辅助说明 |

禁止为了“看起来差不多”随意增减字号。字体替换后应保留原字号，仅在用户明确指出的层级调整。

源码依据：[`design-tokens.ts`](../../apps/web/src/design-tokens.ts)、[`fonts.css`](../../apps/web/src/fonts.css)、[`main.tsx`](../../apps/web/src/main.tsx)。

## 3. 基础令牌

```css
:root {
  --color-brand: #3370ff;
  --color-brand-hover: #2859d9;
  --color-brand-active: #214bbb;
  --color-brand-soft: #e4eeff;
  --color-surface: #ffffff;
  --color-surface-subtle: #f3f4f6;
  --color-page: #ffffff;
  --color-text: #1f242b;
  --color-text-secondary: #586579;
  --color-text-muted: #8a97a9;
  --color-border: #e5e7eb;
  --color-divider: #eceef1;

  --radius-small: 8px;
  --radius-control: 12px;
  --radius-medium: 16px;
  --radius-large: 24px;
  --radius-pill: 999px;
}
```

圆角按语义使用，不能在同一容器上分别写互不一致的上下圆角：

- `8px`：紧凑小控件。
- `12px`：普通输入和下拉控件，不用于可点击按钮。
- `16px`：中型内容卡片。
- `24px`：大型工作区、日历内容容器和浮层。
- `999px`：所有文字按钮、胶囊选择、胶囊输入和列表选择按钮。

### 3.1 按钮圆角与填充图标——强制统一

- 只要控件包含文字并可点击，视觉圆角统一为 `999px`，包括主按钮、次按钮、课程列表项、学生列表项、资料筛选项和资料行。
- 只有图标的按钮必须宽高相等并使用 `border-radius: 50%`，不得出现圆角方块。
- 序号圆标同样使用 `border-radius: 50%`；例如课程单元序号固定为正圆。
- 内容卡片、输入框、日历事件不是按钮，不得为了统一按钮而强行改成胶囊。
- 导航箭头、添加图标使用与侧边栏同源的实心 SVG：`WorkspaceIcon variant="filled"`。禁止临时混入细线图标。
- 主按钮 Hover 必须保持白字和品牌色，不得退回白底或丢失蓝色：

```css
.teacher-portal-shell .ant-btn-primary:not(:disabled) {
  border-radius: 999px;
  color: #fff;
  background: #3370ff;
}

.teacher-portal-shell .ant-btn-primary:not(:disabled):hover,
.teacher-portal-shell .ant-btn-primary:not(:disabled):focus-visible {
  color: #fff;
  background: #2859d9;
}

.ui-icon-button {
  width: 36px;
  height: 36px;
  border-radius: 50%;
}
```

## 4. 胶囊选择器——强制统一

### 4.1 使用范围

适用于 2–5 个互斥选项，例如：

- 进行中 / 课时地图 / 作业与证据。
- 日 / 周 / 月。
- 进行中 / 已完成。
- 密码登录 / 验证码登录。

侧边栏导航和状态标签不是“分段选择器”，不套用本节结构。

### 4.2 固定视觉

| 部位 | 规范 |
|---|---|
| 外轨道 | 高度 `48px`；内边距 `4px`；间距 `2px`；背景 `#F3F4F6`；无边框；圆角 `999px` |
| 单个选项 | 高度 `40px`；水平内边距 `12–16px`；透明背景；圆角 `999px` |
| 未选中文字 | `#8A97A9`；`14–15px`；字重 500 |
| 已选块 | 白色 `#FFFFFF`；不得使用浅蓝实心块 |
| 已选文字 | 品牌蓝 `#3370FF`；字重 600 |
| 已选阴影 | `0 2px 8px rgb(31 52 87 / 9%)` |
| 焦点 | `0 0 0 3px rgb(51 112 255 / 16%)`，必须支持 `:focus-visible` |

标准实现：

```css
.ui-segmented {
  display: inline-flex;
  gap: 2px;
  min-height: 48px;
  padding: 4px;
  border: 0;
  border-radius: 999px;
  background: #f3f4f6;
}

.ui-segmented > button {
  min-width: 48px;
  min-height: 40px;
  padding: 0 12px;
  border: 0;
  border-radius: 999px;
  color: #8a97a9;
  background: transparent;
  font-size: 15px;
  font-weight: 500;
}

.ui-segmented > button[aria-pressed="true"],
.ui-segmented > button.is-active {
  color: #3370ff;
  background: #fff;
  box-shadow: 0 2px 8px rgb(31 52 87 / 9%);
  font-weight: 600;
}

.ui-segmented > button:focus-visible {
  outline: 0;
  box-shadow: 0 0 0 3px rgb(51 112 255 / 16%);
}
```

禁止样式：选中项使用浅蓝色实心背景、外轨道出现明显蓝边、上下圆角不同、选中块紧贴轨道边缘、只靠字重区分选中状态。

### 4.3 工作区 B 标准规格

日程视图、待办状态、课程三视角和学生详情切换采用 B 标准高度：外轨 `40px`、内边距 `3px`、选项高度 `34px`、选项字号 `14px`。总宽度按文案数量确定：日程 `144px`、待办状态 `180px`、课程三视角 `336px`、学生详情 `312px`。时间分布是低层级辅助筛选，单独采用 A 紧凑规格 `132 × 36px`，选项高 `30px`、字号 `13px`。登录页等需要更强触控面积的独立场景继续使用第 4.2 节 `48px` 大触控规格。

## 5. 页面级创建按钮

“新建日程”“新建待办”属于同类页面级创建动作，统一使用以下规格：

| 属性 | 值 |
|---|---|
| 高度 | `40px` |
| 最小宽度 | `116px` |
| 水平内边距 | `16px` |
| 图标 | `16px` |
| 图标风格 | 实心填充 SVG，与侧边栏图标同源 |
| 图文间距 | `8px` |
| 圆角 | `999px` |
| 背景 | `#3370FF` |
| Hover | `#2859D9` |
| Active | `#214BBB` |
| 文本 | 白色、`15px`、字重 600 |

按钮的图标与文字必须作为一个整体居中：`display: inline-flex; align-items: center; justify-content: center; gap: 8px`。Ant Design 的 `.ant-btn-icon` 不得保留额外的 `margin-inline-end`，图标和文字均使用 `20px` 行盒垂直居中。加号使用 `WorkspaceIcon name="plus" variant="filled"` 的实心粗体路径，不得用文本字符 `+` 或细描边 SVG。

所有蓝色主按钮的图标与文字必须共用同一中线；文字允许统一向下 `1px` 作中文字形光学校正，不允许每个页面单独使用不同的顶部偏移。

```css
.ui-create-action {
  display: inline-flex;
  min-width: 116px;
  height: 40px;
  align-items: center;
  justify-content: center;
  gap: 8px;
  padding: 0 16px;
  border: 0;
  border-radius: 999px;
  color: #fff;
  background: #3370ff;
  font-size: 15px;
  font-weight: 600;
}
```

按钮文案必须完整描述动作，使用“新建待办”，不得缩写成含义模糊的“新建”。

## 6. 登录页——冻结

源码：[`LoginPage.tsx`](../../apps/web/src/pages/LoginPage.tsx)、[`LoginEducationNetworkDrawing.tsx`](../../apps/web/src/components/auth/LoginEducationNetworkDrawing.tsx)、[`styles.css`](../../apps/web/src/styles.css)。

### 6.1 页面和卡片

- 页面固定铺满视口并用 Grid 居中：`position: fixed; inset: 0; place-items: center`。
- 页面四周背景为纯白 `#FFFFFF`。
- 卡片宽度：`clamp(880px, 55vw, 1760px)`。
- 卡片高度：`clamp(530px, 61vh, 1060px)`。
- 卡片距离视口最少 `24px`，即最大宽高分别为 `100vw - 48px`、`100dvh - 48px`。
- 左右比例：`54% / 46%`。
- 卡片圆角：`28px`；边框：`1.5px solid #D9E3EE`。
- 阴影：`0 24px 68px rgb(45 55 72 / 12%)`。

### 6.2 左侧插画

- 使用 `1024 × 1152` viewBox 的纯 SVG，不允许 `<image>`、Base64 图片或 CSS 背景图冒充矢量重绘。
- 保留品牌标识、三层协作圆环、六个节点、教师端 / 学生端 / 家长端卡片、中心标识、点阵、投影和底部说明。
- 左侧底色为系统浅蓝，不得换回米黄、浅绿或高饱和渐变。
- SVG 必须随左栏等比缩放，不能单独拉伸其中的建筑、卡片或文字。

### 6.3 右侧登录区

- 背景：侧边栏同源灰 `#F6F7F9`。
- 内容最大宽度：`360px`，水平和垂直居中。
- “欢迎登录”：`24px / 700`。
- 登录方式使用第 4 节标准胶囊选择器。
- 输入框与登录按钮使用完整胶囊圆角；常规高度 `52px`，紧凑桌面高度 `50px`，有效视觉圆角始终为高度的一半。
- 已删除的营销文案不得重新加入。
- 登录接口、手机号规则、密码规则和验证码逻辑不得因视觉调整而改变。

每个导航项内部必须用 Flex 将“`24px` 图标 + `7px` 基础间距 + 两字标签”作为一个整体在 `48px` 高胶囊中垂直居中，禁止使用会把文字列拉满的 `24px minmax(0, 1fr)` 网格。图标容器固定 `24 × 24px` 并 `place-items: center`。头像本身已相对侧栏几何中心左移 `8px`；图标相对胶囊几何中心左移 `8px`，标签左移 `10px`，形成约 `5px` 的最终视觉间距，使头像中心线更准确地穿过图标与文字间隙中心。头像区与导航区的下间距固定为 `28px`。为补偿中文字形视觉重心，“首页”“课程”标签相对数学中心下移 `2px`，其余标签只允许 `0.25px` 的统一光学校正。

## 8. 日程页——冻结

工具栏固定为左右两个区域。左侧从左到右必须是：

1. 页面标题“日程”，`28px / 700`。
2. 日 / 周 / 月标准胶囊选择器。
3. 上一周期圆形按钮。
4. 下一周期圆形按钮。
5. 日期文字，例如“2026年8月9日 星期日”。

右侧只放小号“新建日程”创建按钮，不得把日期、视图切换或其他控件放到右侧。

规则：

- 不显示“今天”按钮；日期切换保持在标题附近的左侧区域。
- 日 / 周 / 月胶囊位于标题之后，并与日期控制一起留在左侧。
- “新建日程”和“新建待办”必须使用第 5 节同一规格。
- 两个日期箭头、“新建日程”和“新建待办”都使用实心填充 SVG；箭头按钮为 `36 × 36px` 正圆。
- 日期箭头底色固定为分段选择器同源灰 `#F3F4F6`，图标为 `17px` 实心粗体路径；Hover 使用 `#E8EAEE`，不得使用浅蓝底或细线箭头。
- 日程标题、待办标题都使用 `28px / 700`；两侧标题栏统一 `72px` 高、`8px 0 16px` 内边距，标题和创建按钮必须在同一水平基线。
- “新建日程”和“新建待办”内部图文必须按第 5 节作为整体精确居中，加号视觉尺寸 `18px`。
- “时间分布”是辅助区标题，固定使用 `16px / 600`，与 `28px / 700` 的“日程”主标题形成清晰层级。
- 日程的“日 / 周 / 月”采用 B 标准档 `144 × 40px`、选项高 `34px`；时间分布的“今日 / 本周 / 本月”采用 A 紧凑档 `132 × 36px`、选项高 `30px`。两者继续共用灰色外轨、白色选中块、品牌蓝文字和轻阴影的视觉语言。[`time-distribution-size-options.svg`](./time-distribution-size-options.svg) 记录时间分布的 A 档选择。
- 日历内容外框统一 `24px` 圆角。
- 日历滚动容器必须同时使用 `overflow` 裁切和圆角 clip，禁止小时横线、月份网格线或背景穿出圆角。
- 工具栏与日历内容之间只保留一个边界，不叠加两条横线。

标准裁切：

```css
.calendar-scroll-region {
  overflow: auto;
  border: 1px solid #e5e7eb;
  border-radius: 24px;
  clip-path: inset(0 round 24px);
  isolation: isolate;
}

.day-calendar,
.week-calendar,
.month-calendar {
  overflow: hidden;
  border-radius: inherit;
}
```

## 9. 课程页——冻结

课程模块采用“两层工作台”：课程级负责选择课时和查看课程全局，单课级是面向教师的**教学成果交付台**。Agent 负责在后台整理洞察、方案和材料；教师端不展示 Agent 的内部流水线，只交付老师需要的文件、必要提醒和验收/调整操作。

### 9.1 课程级三视角

- 顶部固定为 `进行中 / 课时地图 / 作业与证据`，使用第 4.3 节 B 标准胶囊，宽 `336px`。
- `进行中`先展示最近课时及其备课包状态，教师显式进入某节课后才打开单课成果交付台；`课时地图`按单元展示全课程进度；`作业与证据`承接原作业入口。
- 课程级“进行中”首屏只保留一个当前优先事项、最多四个后续课时和一个实心品牌蓝“进入处理”按钮；不得变成统计卡片墙，不得伪造“未来 48 小时”或“自上次访问”等缺少正式数据支持的文案。
- `作业与证据`内部用真实 Assignment、Submission 和已确认批改数量投影“待发布 / 进行中 / 待批改 / 已形成 Evidence / 已关闭”，这些数字只做读取汇总，不新增或回写业务状态。
- 课程级三视角只负责组织课程，不代表单课工作流。进入单课以后，老师面对的唯一阶段结构固定为`课前 / 课上 / 课后`。
- 课程导航在桌面宽屏使用 `280px`，约 `1440px` 视口时收至 `240px`；课时状态必须使用“待判断教学洞察”“Agent 正在生成”“待批准教学计划”这类具体业务语言，不得长期显示泛化的“进行中 / 未完成”。
- 同一课时只显示一个最高优先级状态。选中课时使用 `#E4EEFF`，Hover 后不得掉色；单元和课时按钮均为完整胶囊，单元序号为正圆。

### 9.2 单课三阶段成果交付台

单课首屏顺序固定为：

1. 课时身份：课名、班级、学科、时长、计划日期和当前阶段状态。
2. `课前 / 课上 / 课后`三阶段胶囊：使用 B 标准分段选择器，默认投影当前真实阶段，也允许教师查看其他阶段的信息。
3. 当前阶段的成果与信息：不得再展示`理解 → 方案 → 材料 → 实施 → 复盘 → 下一课`六步导航、`Current Focus`、`本课工作记录`或英文 Kicker。

三个阶段分别只展示：

- **课前**：备课包状态、一个主要操作、`本课重点 / 教学提醒`和五类文件。五类文件固定为教案、课件大纲、课堂练习、板书设计和分层支持。
- **课上**：课堂会用到的课件、练习、板书和分层支持；课堂记录收在单一按需入口中，不与文件抢占首屏。
- **课后**：课程结束后才展示课堂记录、关联作业、学习证据、课后总结和下一课建议；未结束时只显示解释性空态，不提前展开课后表单。

课前备课包状态必须来自真实 `MaterialBundleProjection`：

- 缺少文件时，只显示“准备本课材料 / 补齐剩余材料”这类交付层动作，不暴露洞察、Proposal、TeachingPlan 等内部名词。
- 全部草稿形成后，主操作为“验收本课材料”；一次验收可以提交多个材料版本，但每个版本仍通过正式 Artifact Application Service 显式采用。
- 已验收后，主操作为“打开课堂课件”；“调整材料”在已有文件上生成新版本，旧版本继续保留。
- 任何尚未真实生成、采用或确认的状态不得伪装成已完成。若架构边界要求教师在生成前作正式确认，只在按需抽屉中展示该确认，不得把内部流程重新放回课程主页。

### 9.3 版本、依据与必要确认抽屉

- “版本与生成依据”使用右侧按需抽屉；不得固定成第三列压缩主画布。
- 抽屉默认展示可读来源名称、文件版本、已知缺口和验收/调整边界；原始 ref 与版本向量收在“查看审计标识”下，不能作为老师第一眼看到的内容。
- 只有当前真实状态阻塞完整备课包生成时，才允许出现“继续准备备课包”抽屉；该抽屉一次只呈现不可绕过的正式确认，不展示六步进度图。
- 抽屉宽屏宽度为 `420px`，约 `1440px` 仍以覆盖层打开，不改变主区列宽。
- Agent 只能形成候选或草稿；采用、批准、确认等正式动作继续由教师显式完成。所有正式动作必须说明会写入什么、不会写入什么，并保留旧版本。

### 9.4 空态与加载

- 页面只在首次无任何课程数据时显示整体加载；切换课时或刷新局部投影时保留已有结构，不得用全页 Spinner 让课程树和上下文消失。
- 没有记录时使用解释性空态；阻塞态同时显示原因与可执行恢复入口；运行态显示可查看的 Agent 进度，不伪造百分比。
- 1920 宽屏以 `280px + 主画布`为主，1440 以 `240px + 主画布`为主；小于 `960px` 时才降为单列。

## 10. 学情页——冻结

- 课程标题不得附加“当前学期”；显示为“八年级 3 班数学”这一类纯课程名称。
- API 返回“匿名学习者”时，只在界面层替换为稳定的三个字中文姓名，不修改 learner ref、证据归属或后端数据。
- 学生详情标题下不显示横分割线。
- “近期作业 / 学习证据 / 课堂观察”使用第 4 节胶囊视觉结构，不使用下划线 Tab。
- 学生详情切换采用第 4.3 节 B 标准高度，轨道宽度固定 `312px`。
- “作业与批改”等操作使用品牌蓝胶囊主按钮。
- 学生列表项使用完整胶囊圆角；选中及 Hover 状态必须稳定。

## 11. 资料页——冻结

- 顶部搜索框宽度不超过 `480px`、高度 `44px`、灰底 `#F3F4F6`、圆角 `999px`；搜索图标为 `19px` 实心 SVG。
- 搜索工具栏与下方筛选/文件表格之间保留 `28px` 垂直间距，不得紧贴。
- “最近更新”排序器固定 `128 × 40px`，灰底 `#F3F4F6`、圆角 `999px`，文字 `15px / 600` 居中，右侧使用 `16px` 实心向下箭头。
- “上传资料”使用第 5 节页面级创建按钮规格，上传图标为 `21px` 加粗实心 SVG，图文整体居中；文字只允许 `-2px / +1px` 的水平/垂直光学校正。
- 左侧筛选区不显示“按用途”标题，也不显示“状态”标题或状态下拉；资料库默认显示有效资料，删除/恢复在资料详情中处理。
- 用途筛选从内容区顶部直接开始；每项高 `44px`，使用 `22px` 精制实心文件夹 SVG、`10px` 图文间距和完整胶囊圆角。
- 文件表格只保留“名称 / 类型 / 更新时间”三列，不显示状态列或状态标签；表头上方不显示横分割线。
- 左侧首个用途筛选项与右侧表头处于同一水平起点；表头不得显示“6 项资料”等数量文案。“更新时间”表头及每行时间在最右列右对齐。
- 表头和每一资料行必须复用同一列定义与同一 `12px` 水平内边距；桌面列定义为 `minmax(320px, 1fr) 160px 176px`，确保类型与更新时间逐行严格对齐。
- 表头高度 `28px`、字号 `16px / 600`；资料行高度 `48px`，类型字号 `16px`，更新时间字号 `15px`。表头与第一行之间不得加入额外空白行或网格间距。
- 上传、下载、更新、关联、筛选及资料行按钮统一使用完整胶囊圆角。
- 资料行选中时使用完整浅蓝背景，不显示左侧蓝色缺口或竖线。
- 文件类型图标底座使用正圆。

## 12. 助手页——冻结

- 主输入胶囊宽度不超过 `720px`，使用灰底 `#F3F4F6`、无凸起阴影和完整胶囊圆角。
- 左侧添加和语音使用 `WorkspaceIcon variant="filled"` 实心路径；右侧发送按钮采用 `36 × 36px` 深灰正圆与白色粗体向上箭头，不使用蓝色圆形右箭头。
- 最近工作按钮最大宽度 `300px`，高度至少 `56px`，标题超长时单行省略；不得恢复为 `360px` 以上的长条按钮。
