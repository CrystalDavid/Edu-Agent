# UI 设计

Edu-Agent 使用蓝色主题、Nunito 与 Noto Sans SC 双语字体、胶囊按钮和清晰的页面层级，围绕教师的课程、日程、学情与文件组织界面。

## 设计要点

- **字体**：英文和数字使用 Nunito，中文使用 Noto Sans SC；页面标题 `28px`，正文 `15px`。
- **导航**：侧边栏连接首页、日程、课程、学情、资料与助手。
- **控件**：文字按钮使用胶囊圆角，图标按钮使用正圆，单选切换使用灰色轨道与白色选中块。
- **课时工作台**：围绕课前、课中和课后组织成果；版本与生成依据在按需抽屉中查看。
- **日程**：日历与待办并列展示，日期与视图切换集中在左侧工具栏。
- **状态**：加载、空态、选中、悬停和键盘焦点使用统一样式。

## 开发入口

页面代码位于 [apps/web/src/pages](../../apps/web/src/pages/)。完整颜色、字号、间距、组件 CSS、各页面尺寸与验收方法见 [设计系统](design-system.md)。该文档保留既有视觉规格，便于实现与复核。

调整界面后，用桌面和窄屏检查布局、键盘焦点与文字换行，并运行根目录的 `typecheck`、`test` 和 `build`。浏览器回归命令见 [验证指南](../engineering/validation.md)。
