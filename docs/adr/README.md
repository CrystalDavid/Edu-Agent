# Architecture Decision Records

本目录保存需要长期追溯、不能随当前文档重写而消失的架构决策。

- [教育智能体平台 v0.3.2 勘误与 ADR 包](教育智能体平台v0.3.2勘误与adr包.md) 是项目初始化阶段导入的历史设计来源，原文保留；
- 当前实现与旧设计冲突时，以 [当前架构](../architecture.md)、代码、Migration 和自动化约束为准；
- 新的不可逆决策应使用独立文件，例如 `ADR-0001-<topic>.md`，记录 context、decision、consequences 和 supersession；
- 不通过编辑旧 ADR 抹去历史；如决策变化，新增 ADR 并显式标记取代关系。
